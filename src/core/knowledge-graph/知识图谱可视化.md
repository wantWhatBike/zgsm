## 需求背景
当前已经有了知识图谱的存储、构建功能，现在需要增加知识图谱的可视化功能。
前端代码：@/webview-ui/src/components/settings/ZgsmKnowledgeGraphSettings.tsx</br> 
后端代码：@/src/core/knowledge-graph </br>

## 技术约束
1、前端使用 d3.js （力导布局）进行知识图谱渲染；
2、在浏览器中进行知识图谱渲染；
3、浏览器图谱布局要自适应；

## 实现逻辑
1、触发
在 @/webview-ui/src/components/settings/ZgsmKnowledgeGraphSettings.tsx 增加一个可视化的按钮，点击该按钮，打开一个浏览器链接，打开链接，浏览器渲染知识图谱。
2、查询
后端全量查询出 FileSummary 的数据（仅部分字段，path、dependencies）；

3、构建
以 File 为节点，path为节点名， dependencies 为边，构建图关系，在浏览器中渲染；

4、节点详情
点击某个节点，查询该节点的描述信息，悬浮展示。
